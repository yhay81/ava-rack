# Stack decisions

- Cloudflare Workers: public origin and scheduled retention cleanup
- D1: content-free product event counts
- Cloudflare Rate Limiting: telemetry write protection
- Hono and Hono JSX: routing and server-rendered shell
- Vite+: development, lint, format, type checking, tests, and build
- Browser JavaScript: local rack state and BOOTH URL construction

Better Auth is omitted because there is no server-owned user state. Product data is not collected from BOOTH.
